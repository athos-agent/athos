# Reporting a security problem

Security problems go to us privately, never to a public issue. On this repository's GitHub page, open
**Security → Report a vulnerability** and describe what you found; you will hear back within three working days.

## What counts

Athos's core promise is that a person's know-how stays on their own machine, and that nothing is sent anywhere unless
they ask for it. Any way to break that promise (data leaving the machine on its own, another user or program reading
the store, a secret ending up in a saved piece) is a security problem, as is anything that lets a hook or command run
code the person did not choose to run.
